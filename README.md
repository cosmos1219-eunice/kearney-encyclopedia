# Kearney 백과사전

글로벌 경영 컨설팅 기업 **커니(Kearney, 구 A.T. Kearney)**에 관한 한국어 백과사전입니다. 애플 아쿠아(Aqua) 스타일의 단일 HTML 페이지로 만들었습니다.

- 항목: 개요 · 역사 · 서비스와 산업 · 리서치와 지수 · 인물과 조직문화 · 한국에서의 커니 · 다른 뜻 / 동음이의 · 용어 사전 & FAQ
- 기능: 실시간 검색과 형광 표시, 스크롤 위치 목차, Dock 탐색, Aqua / Graphite 테마 전환, 모바일 대응

## 보기

`kearney-encyclopedia.html`을 브라우저로 열면 됩니다.

## 구조

| 파일 | 설명 |
| --- | --- |
| `shell.html` | 아쿠아 디자인 셸(CSS/JS). `<!--SECTIONS-->` 자리에 본문이 들어갑니다. |
| `sections/*.html` | 항목별 본문 조각. 파일 이름 순서대로 합쳐집니다. |
| `build.sh` | 조각을 셸에 합쳐 `kearney-encyclopedia.html`을 만듭니다. |

```bash
bash build.sh
```

## 제작 방식

멀티 에이전트로 작성했습니다. 작성 에이전트 4개가 섹션을 나눠 동시에 쓰고, 팩트체크 에이전트가 웹 자료로 사실과 섹션 간 일관성을 검증한 뒤 조립했습니다.

> 이 문서는 Kearney의 공식 자료가 아닙니다. 수치와 연도는 공개 자료를 기준으로 했으며, 출처가 엇갈리는 부분은 본문에 단서를 달았습니다.
